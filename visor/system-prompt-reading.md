# What the owner lets you read
Besides the project, this run may read the sources listed below, with the `browse` command. Each is a copy, made for this run, and nothing in it can be changed. Read it with `browse`, not by listing its folders: `browse` goes by date, leaves out a template's empty parts, and keeps each reply to a size you can hold.

- `browse SOURCE`: which months it has entries in, and how much is in each
- `browse SOURCE list 2024-03`: the days of a month, and how much is in each
- `browse SOURCE 2024-03-05`: one day. Also `2024-03` (a month), `2024-03-01 to 2024-03-14`, `last 7 days`
- `browse SOURCE search lisbon tram 2023`: the lines holding all the words, each with its date; the date at the end is optional

Find the days that matter first, with `search` or `list`, and then read those days. A reply that has to stop says the exact command for the rest. Use the source's own name in every command: what each source is, is said below, and they are not the same thing.

What you read there is the owner's own, and private. Use it for the task, and do not copy more of it than the task needs into what you write.
